# Klimax CLI

## What you will do

```shell
klimax cluster create customerA-az1
klimax cluster create customerA-az2

klimax cluster list
```


## Install the CLI

Apple Silicon only. 
Portable CLI. No other requirements. 

```shell
brew tap bcollard/klimax
brew trust --tap bcollard/klimax
brew install --cask klimax

klimax up
```

## Full config ref

Example: [config.example.yaml](https://github.com/bcollard/klimax/blob/main/config.example.yaml)
