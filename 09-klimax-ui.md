# Klimax UI

## A native companion app

Open-source, native macOS app (Swift) that gives an overview of 
- your VM
- KinD clusters
- registry mirrors
- docker containers and compose projects

## Screenshots

![Klimax UI](https://klimax.dev/assets/home-view.png)



## How it works

Requirements:
- klimax CLI
- kubectl, docker, and helm on PATH


## Install

```shell
brew install --cask klimax-ui
```
